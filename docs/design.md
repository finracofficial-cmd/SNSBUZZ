# 愛されポンコツ診断（ポンコツ図鑑）設計メモ v2

レポート『SNSでバズる診断コンテンツ調査』の第1位案「自虐ミームラベル診断」を、過去の成功例を参考にして作り込んだ版。

- 名前はすべて仮。`site/assets/config.js` を変えれば全ページに反映される。
- 参考にした事例の調査: `research_notes/v2_benchmarks/result_anatomy.md`
- お金まわり: `docs/monetization.md`

## 位置づけと競合

- 中国のSBTI（2026年4月）にあたる「MBTIの代わりに、笑える自虐ラベルを返す診断」の日本版。
- 日本の直接の競合は**悪口診断**（waruguchi16.jp）。月1,945万PVの実績があり、ラッコM&Aで売りに出ている案件とみられる。詳細は [競合チェック](competitor_check.md)。
- 悪口診断は他人をディスる毒で売れた。こちらは逆を行き、「自分を笑って、最後は愛される」自虐で差別化する。

入れなかったもの:

- 結果の前の全画面広告（悪口診断にはある）
- 相性をLINE登録の裏に隠すこと（ラブタイプ診断はそうしている）
- 自由に書きこめる掲示板（10代向けには荒れるリスクが高い）
- 毎日の運勢。Stripeの禁止業種である「占い」に見えるため

## 判定の仕組み

### 4つの軸

| 軸 | 片側 | もう片側 |
|---|---|---|
| E | 省エネ | 全力 |
| S | ひとり好き | 人たらし |
| P | 計画派 | ノリ派 |
| M | 考えすぎ | 秒で忘れる |

- 1軸あたり5問、計20問（約2分）。
- 選択肢は −3 / −1 / +1 / +3 の4択。1軸5問の合計は必ず奇数になるので、**引き分けが起きない**。
- 選択肢の並びは、質問ごとに固定の順でシャッフルしている（強弱の順に見えないように）。

### 隠しタイプ（4種類）

判定はこの順に見て、先に当たったものを採用する。

1. **幻のしっかり者（S4）**: 4軸の合計の絶対値を足して4以下。理論出現率0.8%。
2. **スマホと融合した人（S1）**: スマホ系の選択肢（Q1・Q5・Q12）を3つとも選ぶ。
3. **金欠の妖精（S2）**: お金系の選択肢（Q11・Q15・Q20）を3つとも選ぶ。
4. **食欲の化身（S3）**: 食べもの系の選択肢（Q9・Q11・Q16）を3つとも選ぶ。

タグ付きの選択肢は、極端な答え（±3）にはなるべく置かない。強く振り切った人が自動的に隠しタイプへ流れないようにするため。

### 人によって変わる部分

- **ポンコツ純度**: 4軸の振れ幅の平均を50〜99%にのせたもの。称号は 90%以上が「殿堂入り」、80%以上が「ガチ勢」、65%以上が「正統派」、それ未満が「ゆるめ」。
- **4軸の％と一言**: 各軸の振れ幅を3段階に分け、段階ごとの一言を出す（全24通り）。
- **裏タイプ**: いちばん振れ幅の小さい軸をひっくり返したタイプ。
- **成分表**: 原材料名（タイプごと）、内容量＝純度、栄養成分表示＝4軸の％。
- **レア度**: 診断完了が200件になるまでは、全員がランダムに答えた場合の理論値を「理論値」と明記して出す。200件を超えたら、実際の集計に切り替える。

### 相性

- 軸ごとの組み合わせで点を足す。
  - 「省エネ/全力」「ひとり好き/人たらし」は、ちがうほど補い合う。
  - 「計画派/ノリ派」は、そろうほどペースが合う。
  - 「考えすぎ/秒で忘れる」は、そろうと少し有利。
- 点を52〜99%にのせる。90%以上が「運命の相方」、80%以上が「名コンビ」、68%以上が「いい感じ」、それ未満が「刺激しあう仲」。同じタイプ同士は「分身」。
- いちばん点が高い相手は、必ずデータ上の相性◎（上2つの軸を反転したタイプ）と一致する（テストで確認）。
- 隠しタイプの人は、ふだんの軸で計算する。

### 質問一覧

（ ）内は点数。「スマホ」「金欠」「食欲」は、隠しタイプの条件になる選択肢。

- とりあえずスマホを見てたら昼（−1・スマホ）
- 朝から出かける予定を入れてある（+1）
- やりたいことが多すぎて朝からフル稼働（+3）

**Q2（ひとり好き ⇔ 人たらし）初対面の人ばかりの集まり。どうする？**

## 結果ページの構成

1. あなたは…（キャラ・ラベル・一言キャッチ・称号と純度・ほめ言葉・痛い一行）。隠しタイプは専用の帯を出す
2. 〇〇さんとの相性（おさそいリンクから来た人だけ）
3. 画像を保存してストーリーズへ ／ X・LINE・コピー・送る ／ 友達と相性をくらべる。アプリ内ブラウザでは、ブラウザで開き直す案内を出す
4. 純度・レア度・裏タイプのタイル
5. もくじ（上に固定。性格・成分表・恋愛・友達・学校・トリセツ・相性・完全版）
6. 基本の性格（愛されポイント3・ポンコツポイント3・4軸の％と一言）
7. 成分表（成分表カードの保存ボタンつき）
8. あるある5
9. 恋愛（恋愛あるある2）
10. 友達・グループでは（役割名・推し活・トーク/SNS・休日・復活法）
11. 学校・バイト・仕事（向いてるかもしれないバイト・仕事3）
12. トリセツ（こうしてくれるとうれしい3・これはやめてね3・生息地・口ぐせ）
13. 相性（相性◎・刺激しあう相手・友達との相性・全タイプとの相性）
14. 完全版トリセツ（予告・中身の一覧・価格・購入／コード）
15. みんなで遊ぶ（グループ診断をつくる）

タイプページ（`/t/NN/`）にも同じ読みものを載せている。検索とシェアの着地点を兼ねる（16Personalitiesのタイプページと同じ役割）。

## 拡散の仕組み

| 仕組み | 中身 |
|---|---|
| 結果カード（9:16） | キャラ・ラベル・純度・痛い一行・純度/レア度/相性◎のタイル。完全版を買った人はゴールド枠 |
| 成分表カード（9:16） | 食品表示のパロディ。自分の％が入るので、同じタイプの人ともちがう画像になる |
| ふたりの相性カード（9:16） | ふたりのキャラ・名前・相性％・ランク・コメント |
| タイプ別OGP | `/t/NN/` と `/i/NN/`。ペア用・グループ用のOGPもある |
| おさそいリンク | `/i/NN/?f=結果&n=名前`。開いた人が診断すると、ふたりの相性が出る。比べた相手は図鑑に「出会ったタイプ」として登録される |
| グループ診断 | `/g/?id=xxxx`。メンバーとタイプ、役割（幹事役・ムードメーカー・切り込み隊長・参謀・癒し担当・聞き役・自由人）、いちばん相性のいいペア。最大50人、90日で閲覧不可 |
| 図鑑のコンプリート | 自分と、相性を比べた友達のタイプで「出会ったタイプ x/20」が埋まる。隠しタイプは出会うまでシルエット |
| SNS運用素材 | `npm run cards` で、全タイプの紹介スライドと結果カードの見本を書き出す |

## 計測とKPI

### 記録するもの

Cloudflare D1 の `counters` に、回数だけを記録する。個人を識別する情報は受け取らない。

| キー | 意味 |
|---|---|
| `start` / `done:N` | 診断開始／タイプ別の完了 |
| `share:<ボタン>` | 押されたシェアボタン（image・label-image・gold-image・x・line・link・native・invite・pair-image など） |
| `ref` | シェアURL・おさそいリンクからの流入 |
| `group:create` / `group:join` | グループの作成・参加 |
| `premium:checkout` / `premium:paid` / `premium:code:<コード>` | 完全版の決済開始・支払い完了・コード利用 |
| `day:YYYY-MM-DD:<キー>` | 上のキーの日別（日本時間） |

### 目標（推定値）

| 指標 | 計算 | 目標 |
|---|---|---|
| 完了率 | done ÷ start | 75%以上（20問に増やしたので、前の版の80%から少し下げた） |
| シェア率 | share ÷ done | 30%以上 |
| おさそい率 | share:invite ÷ done | 10%以上 |
| 完全版の購入率 | premium:paid ÷ done | 0.3%（幅は0.1〜1%） |

## 公開前に人がやること

1. **キャラを、人の手で描いたイラストに差し替える**: 20体分。`site/assets/chara.js` の `charaSVG()` を画像ファイル参照に替える。模倣への一番の守りになる。
2. **販売事業者の情報を埋める**: `site/assets/config.js` の `seller` に入れる（特定商取引法に基づく表記で使う）。
3. **決済の審査を確認する**: Stripe（またはKOMOJU）に、「エンタメ心理テストの有料レポート」が通るか確認する。そのうえで `STRIPE_SECRET_KEY`、`STRIPE_PRICE_ID`、`PREMIUM_SECRET` を設定する。
4. **名前・ドメイン・商標を確認する**。
5. **自社のX・TikTok・Instagramを開設する**: 公開の1〜2週間前から、あるあるカルーセルを流す。公開後も運用を止めない。
6. **インフルエンサーに依頼するときは「PR」と表記する**。
