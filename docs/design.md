# 愛されポンコツ診断（ポンコツ図鑑）設計メモ

レポート『SNSでバズる診断コンテンツ調査』の第1位案「自虐ミームラベル診断」の試作。名前はすべて仮で、`site/assets/config.js` を変えれば全ページに反映される。

## 位置づけと競合

- 中国の SBTI（2026年4月）にあたる「MBTIの代わりに、笑える自虐ラベルを返す診断」の日本版。
- 日本に本家の日本語版や、日本向けに作り直したクローンは見つからなかった（[競合チェック](competitor_check.md)）。
- ただし「ネタ系ラベルの16タイプ診断」は、**悪口診断**（waruguchi16.jp、2026年2月頃公開）がすでに大きく当てている。
  - PR TIMES（2026-08-06、自社発表）では「1か月で1,945万PV」。ラッコM&A案件のピーク月とまったく同じ数字なので、売りに出ているのはこの悪口診断である可能性が高い（推測）。
  - 需要は証明済みで、首位はピークから減速して売却中、という状況。
- 差別化の軸（悪口診断との違い）:

  | | 悪口診断 | 愛されポンコツ診断 |
  |---|---|---|
  | トーン | 他人や人間関係をディスる毒 | 自分を笑って最後は愛される自虐 |
  | 結果の締め方 | 辛口 | ほめ言葉＋痛いところを突く一行 |
  | キャラ | 害獣モチーフ | かわいい動物モチーフ |
  | タイプの呼び方 | 英字4文字コード | 図鑑No.＋ラベル |
  | 仕掛け | なし | 隠しタイプ、純度％、レア度、図鑑 |

## 判定の仕組み

### 4つの軸

1. 省エネ ⇔ 全力
2. ひとり好き ⇔ 人たらし
3. 計画派 ⇔ ノリ派
4. 考えすぎ ⇔ 秒で忘れる

- 2×2×2×2で16タイプ。
- 各軸3問ずつ、計12問（約1分）。

### 採点

- 選択肢は −2 / −1 / +1 / +2 の4択。表示順は質問ごとに固定でシャッフルし、強弱の並びが見えないようにしている。
- **引き分け**: 軸の合計が0になるのは「±2が1つと∓1が2つ」の組だけ。そのときは±2を選んだ側に倒す。
- **隠しタイプ「スマホと融合した人」**: 「スマホ／動画」の選択肢3つ（Q1・Q5・Q12）を全部選ぶと出る。理論出現率は1.6%。
- **ポンコツ純度**: 4軸の振れ幅の平均を50〜99%にのせたもの。
  - 称号は 90%以上が「殿堂入り」、80%以上が「ガチ勢」、65%以上が「正統派」、それ未満が「ゆるめ」。
  - 同じタイプの友達どうしでも数字が違うので、比べる話題になる。
- **レア度**:
  - 診断完了が200件たまるまでは、全員がランダムに答えた場合の理論値を「理論値」と明記して出す。
  - 200件を超えたら、実際の集計（`/api/stats`）に切り替える。

### 文言のルール

- 容姿・知能・体型・病気を連想させる言葉は使わない。
- 欠点は必ず「愛される欠点」として書き、ほめ言葉から入る。
- 「MBTI」「SBTI」という名前も、英字4文字のコードも使わない（商標と、模倣に見えるリスクを避けるため）。
- 実在の人物・作品・キャラクターは出さない。

### 質問一覧

（ ）内は点数。「隠し」は隠しタイプの条件になる選択肢。

**Q1（省エネ ⇔ 全力）待ちに待った休日。まず何する？**
- 昼まで寝る。布団から出ないのが正義（−2）
- とりあえずスマホを見てたら昼（−1・隠し）
- 朝から出かける予定を入れてある（+1）
- やりたいことが多すぎて朝からフル稼働（+2）

**Q2（ひとり好き ⇔ 人たらし）初対面の人ばかりの集まり。どうする？**
- 知ってる人のそばから離れない（−2）
- 話しかけられたら話す（−1）
- 近くの人に自分から話しかける（+1）
- 帰るころには全員と連絡先を交換してる（+2）

**Q3（計画派 ⇔ ノリ派）旅行の準備は？**

## シェアの設計

- **結果画面**
  - いちばん上にキャラ、ラベル、称号・純度、ほめ言葉、蛍光ペン風の「痛いところを突く一行」を置く。
  - その直下にシェアボタンを置く（ストーリーズ用画像、X、LINE、リンクコピー、OSの共有）。
- **ストーリーズ／TikTok用画像（1080×1920）**: ブラウザのcanvasで作る。
  - 載せるもの: キャラ、図鑑No.、ラベル、称号・純度、ほめ言葉、痛い一行、純度・レア度・相性のタイル、ドメイン、ハッシュタグ。
  - スマホでは共有シートに画像を直接渡す（Web Share API）。使えない環境では長押し保存とダウンロードに切り替える。
- **X・LINE用URL**: `/t/NN/?s=シェアID`。
  - `/t/NN/` はタイプ別のOGP画像（`site/og/NN.png`）を持つ静的ページで、着地するとそのタイプの図鑑ページと「あなたは何タイプ？」ボタンが出る。
  - 隠しタイプは `/t/00/`。検索には出さない（robots.txt）。
- **投稿文**: 純度と称号で人ごとに変わる。例:「私は【布団の守護神（ガチ勢）】でした。ポンコツ純度87%」＋痛い一行＋ハッシュタグ。
- **図鑑**
  - 16タイプを一覧で見せ、自分のタイプに「あなた」の印をつける。
  - 隠しタイプは引き当てるまでシルエットで隠す。
  - 「友達や推しを当てはめるなら？」で遊びを広げる。
- **SNS運用素材**: `npm run cards` で、タイプ紹介スライド（あるある3つ）とシェア画像の見本を全タイプ分書き出す。公開前の「全16タイプあるある」カルーセルに使う。

## 計測とKPI

### 記録するもの

Cloudflare D1 の `counters` テーブルにカウントだけを積む。個人を識別する情報は受け取らない。

| キー | 意味 |
|---|---|
| `start` | 診断開始 |
| `done` / `done:N` | 診断完了（合計／タイプ別） |
| `share:x` / `line` / `link` / `native` / `image` | シェアボタンの押下 |
| `ref` | `?s=` 付きURLからの流入 |
| `day:YYYY-MM-DD:キー` | 上の各キーの日別（日本時間） |

### 確認方法

`GET /api/stats?all=1` に `Authorization: Bearer <KPI_TOKEN>` を付けると全カウンタを返す。

### 目標（レポートの推定値）

| 指標 | 計算 | 目標 |
|---|---|---|
| 完了率 | done ÷ start | 80%以上 |
| シェア率 | share ÷ done | 30%以上（参考：デュエマ文明診断の約18%） |
| 流入効率 | ref ÷ share | — |

- 共有シートやストーリーズの先は外から見えないので、ボタンの押下数で代用している。
- シェア率が10%を切ったら、結果画面を作り直す。

## 公開前に人がやること

1. **キャラを人の手で描いたイラストに差し替える**
   - いまのSVGは仮。模倣への一番の防御はキャラIPになる。
   - AIだけで生成した絵は、著作権で守られない可能性がある（文化庁の考え方）。
   - `site/assets/chara.js` の `charaSVG()` を画像ファイル参照に替えれば差し替えられる。
2. **ラベルを投票で確定する**（上の予備案と入れ替え）。
3. **名前、ドメイン、商標を確認する**
   - 「ポンコツ図鑑」「愛されポンコツ診断」は、Web上で目立つ先行利用が見つからなかった。ただし J-PlatPat での商標確認とドメイン取得はまだ。
4. **自社のX・TikTok・Instagramアカウントを開設する**
   - 公開の1〜2週間前から、あるあるカルーセルを流す。
   - 公開日は11月上〜中旬（レポートの提案）。
   - 公開後も運用を止めない。ラッコ案件は、自社SNSを止めてPVの約95%を失っている。
5. **インフルエンサーに依頼するときは「PR」と表記する**
   - 報酬や台本がある「やってみた」投稿には必ず表記する。
   - 2026年8月に、写真アプリSNOWへのステマ措置命令の前例がある。
6. **広告（AdSense）を入れるときの注意**
   - 結果ボタンとシェアボタンの近くには置かない（誤クリック誘導はポリシー違反になる）。
   - プライバシーポリシーページを追加する。
