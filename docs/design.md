# 愛されポンコツ診断（ポンコツ図鑑）設計メモ v3

レポート『SNSでバズる診断コンテンツ調査』の第1位案「自虐ミームラベル診断」を、成功例を参考に作り込んだもの。v3では、診断を**かんたん診断（12問）**と**くわしい診断（＋24問）**の2段階に分けた。くわしい診断の結果は、ふんわりした部分だけを無料で見せる。くわしい部分にはモザイクをかけ、完全版を買うと読めるようにした。

- 名前はすべて仮。`site/assets/config.js` を変えれば全ページに反映される。
- 調査メモ
  - v2: `research_notes/v2_benchmarks/`（結果ページの作り・マネタイズ）
  - v3: `research_notes/v3/paywall_patterns.md`（チラ見せ・ペイウォール・法規制）、`research_notes/v3/two_tier_and_viral.md`（2段階診断・二つ名・友達クイズ・2026年の10代トレンド）
- お金まわり: `docs/monetization.md`

## 位置づけと競合

- 中国のSBTI（2026年4月）にあたる、「MBTIの代わりに、笑える自虐ラベルを返す診断」の日本版。
- 日本の直接の競合は**悪口診断**（waruguchi16.jp）。詳しくは [競合チェック](competitor_check.md)。
  - 月1,945万PVの実績がある。
  - ラッコM&Aで売りに出ている案件とみられる。
- 悪口診断は、他人をディスる毒で売れた。こちらはその逆で、「自分を笑って、最後は愛される」自虐で差別化する。

## v3の全体像

```
ホーム ─┬─ かんたん診断（12問・約1分）─→ かんたん結果（無料・全部読める）
        │                                   └─ 「くわしい診断の続き（あと24問）」
        └─ くわしい診断（36問・約4分）──→ レポート全8章
                                            第1章 ステータス ……………… 無料（二つ名の解説を1つ見本で全文）
                                            第2〜3章 パラメータ・恋愛タイプ … 見出し・段階・冒頭の一言は無料、くわしい部分はモザイク
                                            第4〜8章 本当のあなた ほか ……… 見出しと予告は無料、本文はモザイク
                                            → 完全版（390円・買い切り）でモザイクが外れる
```

- 12問の結果（タイプ）は、24問を足しても**変わらない**。くわしい診断は「別の診断」ではなく「同じタイプの続きの章」。
  - 成功例が、詳細版でタイプを出し直していないことに合わせた。
  - 例: LoveType16の64通り、16PersonalitiesのA/T、ビッグファイブのファセット。
- かんたん診断を終えた人には、「続きから24問」で入れる入口を出す。進捗は「13/36問」から始まる。
- くわしい診断は8問ずつの3章に分けた。章の終わりごとに「恋愛のクセを読みとりました」のような途中ごほうびを出す。

## 判定の仕組み

### 4つの軸（かんたん診断）

| 軸 | 片側 | もう片側 |
|---|---|---|
| E | 省エネ | 全力 |
| S | ひとり好き | 人たらし |
| P | 計画派 | ノリ派 |
| M | 考えすぎ | 秒で忘れる |

- 1軸あたり3問、計12問（約1分）。
- 選択肢は −3／−1／+1／+3 の4択。1軸3問の合計は必ず奇数になるので、**引き分けが起きない**（−9〜+9）。
- 選択肢の並びは、質問ごとに決まった順でシャッフルする（強弱の順に見えないように）。

### 6つのパラメータ（くわしい診断）

| パラメータ | 高いときの形容 | 低いときの形容 | 章 |
|---|---|---|---|
| 恋愛積極度 | 恋に全力な | 恋はのんびりな | 第1章 恋とヤキモチ |
| ヤキモチ度 | ヤキモチ焼きの | 心が広すぎる | 第1章 |
| さみしがり度 | さみしがりの | ひとりでも平気な | 第2章 さみしさと妄想 |
| 妄想力 | 妄想がとまらない | 現実しか見ない | 第2章 |
| 推し活熱量 | 推しに生かされている | 自分が推しの | 第3章 推しと笑い |
| ツッコミ力 | ツッコミが鋭い | 天然ボケの | 第3章 |

- 1パラメータあたり4問。選択肢は 0〜3 点で、合計 0〜12 点を 0〜100% にのせる。
- 段階: 33%以下が「低め」、66%以下が「ふつう」、それより上が「高め」。
- ランク: 85%以上が S、67%以上が A、42%以上が B、25%以上が C、それ未満が D。
- **二つ名**: 50%からいちばん離れたパラメータの「高い／低い」の形容をタイプ名の前につける。
  - 例:「ヤキモチ焼きの」＋「既読スルー職人」
  - 同点のときに同じパラメータばかり選ばれないよう、比べ始める位置をタイプごとにずらす。
  - 形容12種 × 20タイプ ＝ 240通り。
- **恋愛タイプ**（8種）: 恋愛積極度・ヤキモチ度・さみしがり度の3つが58%以上かどうかの組み合わせ。

| 積極 | ヤキモチ | さみしがり | 恋愛タイプ | 相性のいい恋愛タイプ |
|---|---|---|---|---|
| − | − | − | マイペース恋愛型 | 一途なハンター型 |
| − | − | ＋ | かまって待ち型 | 全力ハグ型 |
| − | ＋ | − | 静かに燃える型 | さっぱり告白型 |
| − | ＋ | ＋ | こっそりヤキモチ型 | ひっつき虫型 |
| ＋ | − | − | さっぱり告白型 | 静かに燃える型 |
| ＋ | − | ＋ | ひっつき虫型 | こっそりヤキモチ型 |
| ＋ | ＋ | − | 一途なハンター型 | マイペース恋愛型 |
| ＋ | ＋ | ＋ | 全力ハグ型 | かまって待ち型 |

- **ステータス**（10項目のレーダー）
  - 4軸: 全力・人たらし・ノリ・切りかえ。かんたん診断と同じ値。
  - 6パラメータ: 恋愛積極・ヤキモチ・さみしがり・妄想・推し活・ツッコミ。
  - 無料では、ランクと4軸の％を見せる。6パラメータの％はモザイク。

### 隠しタイプ（4種類）

判定はこの順に見て、先に当たったものを採用する。くわしい診断でも、タイプはかんたん診断の12問だけで決まる。

1. **幻のしっかり者（S4）**: 4軸すべての合計が ±1 で、しかも ±3 の答えが4つ以下。理論出現率0.74%で、いちばんレア。
2. **スマホと融合した人（S1）**: スマホ系の選択肢（Q1・Q4・Q5）を3つとも選ぶ。
3. **金欠の妖精（S2）**: お金系の選択肢（Q7・Q11・Q12）を3つとも選ぶ。
4. **食欲の化身（S3）**: 食べもの系の選択肢（Q7・Q8・Q9）を3つとも選ぶ。

タグ付きの選択肢は、極端な答え（±3）にはなるべく置かない。強く振り切った人が自動的に隠しタイプへ流れないようにするため。

### 人によって変わる部分

| 項目 | 中身 |
|---|---|
| ポンコツ純度 | 4軸の振れ幅の平均を50〜99%にのせたもの。称号は、90%以上が「殿堂入り」、80%以上が「ガチ勢」、65%以上が「正統派」、それ未満が「ゆるめ」 |
| 4軸の％と一言 | 振れ幅を3段階に分けて、段階ごとの一言を出す（全24通り） |
| 裏タイプ | いちばん振れ幅の小さい軸をひっくり返したタイプ |
| 成分表 | 原材料名（タイプごと）、内容量＝純度、栄養成分表示＝4軸の％ |
| レア度 | 診断完了が200件になるまでは、全員がランダムに答えた場合の理論値を、「理論値」と明記して出す。200件を超えたら実際の集計に切り替える |
| 二つ名・恋愛タイプ・ステータス | くわしい診断のみ（上を参照） |

### 結果コード

結果はURLに入れて持ち運ぶ（サーバーに回答を保存しない）。

- かんたん診断: `<タイプ36進>~<E>_<S>_<P>_<M>`（例 `6~-3_5_1_-1`）
- くわしい診断: 末尾に `~<6パラメータの36進>` をつける（例 `6~-3_5_1_-1~9a3c07`）
- サーバー側の検査: `functions/_lib/http.js` の `RESULT_CODE`

### 相性

- 軸ごとの組み合わせで点を足す。
  - 「省エネ/全力」「ひとり好き/人たらし」は、ちがうほど補い合う。
  - 「計画派/ノリ派」は、そろうほどペースが合う。
  - 「考えすぎ/秒で忘れる」は、そろうと少し有利。
- 点を52〜99%にのせる。

  | 相性 | ランク名 |
  |---|---|
  | 90%以上 | 最強の相方 |
  | 80%以上 | 名コンビ |
  | 68%以上 | いい感じ |
  | それ未満 | 刺激しあう仲 |
  | 同じタイプ同士 | 分身 |

  v2の「運命の相方」は、占いに見えないように「最強の相方」に変えた。
- いちばん点が高い相手は、必ずデータ上の相性◎（上2つの軸を反転したタイプ）と一致する（テストで確認）。
- 隠しタイプの人は、ふだんの軸で計算する。

## ページの構成

### かんたん診断の結果（全部無料）

1. あなたは…: キャラ・ラベル・一言キャッチ・称号と純度・ほめ言葉・痛い一行。隠しタイプは専用の帯を出す
2. 〇〇さんとの相性（おさそいリンクから来た人だけ）
3. 画像の保存とシェア
   - 結果カード・成分表カード・プロフ帳カード
   - X・LINE・コピー・送る
   - アプリ内ブラウザでは、ブラウザで開き直す案内を出す
4. **くわしい診断の入口**
   - 「？？？な」＋タイプ名（二つ名をぼかしたもの）
   - 「続きから24問・約3分」
5. 純度・レア度・裏タイプのタイル
6. 相性（相性◎・刺激しあう相手・友達との相性・全タイプとの相性）

  - モザイクのタップ

  - プロフ帳カード（無料）

### タイプページ（`/t/NN/`）

性格・恋愛・友達・学校・トリセツ・相性の読みものを、全タイプ分すべて無料で載せている。検索とシェアの着地点を兼ねる（16Personalitiesのタイプページと同じ役割）。

## 計測とKPI

### 記録するもの

Cloudflare D1 の `counters` に、回数だけを記録する。個人を識別する情報は受け取らない。

| キー | 意味 |
|---|---|
| `start` / `done:N` | 診断開始／タイプ別の完了（12問を答え終えた時点。くわしい診断を最初から始めた人も含む） |
| `detail:start` / `detail:done` | くわしい診断の開始／完了 |
| `share:<ボタン>` | 押されたシェアボタン（image・label-image・nick-image・status-image・prof-image・x・line・link・native・invite・quiz・pair-image など） |
| `ref` | シェアURL・おさそいリンクからの流入 |
| `quiz:create` / `quiz:answer` / `quiz:done` | わたしクイズの出題・回答開始・回答完了 |
| `paywall:view` / `paywall:cta` / `paywall:ask` | 購入案内の自動表示／ボタンからの表示／「おうちの人に頼む」 |
| `group:create` / `group:join` | グループの作成・参加 |
| `premium:checkout` / `premium:paid:solo` / `premium:paid:duo` / `premium:code:<コード>` | 完全版の決済開始・支払い完了・コード利用 |
| `day:YYYY-MM-DD:<キー>` | 上のキーの日別（日本時間） |

### 目標（推定値）

| 指標 | 計算 | 目標 |
|---|---|---|
| かんたん診断の完了率 | done ÷ start | 85%以上（12問にしたので、v2の20問より上げた） |
| くわしい診断への移行率 | detail:start ÷ done | 25%以上 |
| くわしい診断の完了率 | detail:done ÷ detail:start | 80%以上 |
| シェア率 | share ÷ done | 30%以上 |
| おさそい・クイズ率 | (share:invite＋quiz:create) ÷ done | 12%以上 |
| 完全版の購入率 | premium:paid ÷ detail:done | 1.5%（幅は0.5〜3%） |

## 公開前に人がやること

1. **キャラを、人の手で描いたイラストに差し替える**
   - 20体分。`site/assets/chara.js` の `charaSVG()` を、画像ファイルを参照する形に替える。
   - 模倣への一番の守りになる。
2. **販売事業者の情報を埋める**: `site/assets/config.js` の `seller` に入れる（特定商取引法に基づく表記で使う）。
3. **決済の審査を確認する**
   - Stripe（またはKOMOJU）に、「エンタメ心理テストの有料レポート」が通るか確認する。
   - そのうえで、`STRIPE_SECRET_KEY`、`STRIPE_PRICE_ID`、`PREMIUM_SECRET` を設定する。
4. **名前・ドメイン・商標を確認する**。
5. **自社のX・TikTok・Instagramを開設する**
   - 公開の1〜2週間前から、あるあるカルーセルを流す。
   - 公開後も運用を止めない。
6. **インフルエンサーに依頼するときは「PR」と表記する**（ステマ告示）。

## 文言のルール

`content/BRIEF.md`（タイプの文言）と `content/BRIEF_v3.md`（パラメータ・恋愛タイプ・完全版）を参照。

- タイプの文言は `content/types/NN.json`、パラメータの解説は `content/params.json`、恋愛タイプは `content/love.json` にある。
- 有料の文章（`premium`・`detail` など）は、ビルドのときに `functions/_lib/premium.js` にだけ書き出す。ブラウザに配る `site/assets/types.js` には入らない。
- 文言を直したら、次の2つを実行する。

```sh
node scripts/validate-content.mjs   # 文字数・NGワード（占いの語・予言の語を含む）の検査
npm run content                     # types.js と premium.js の生成
```
