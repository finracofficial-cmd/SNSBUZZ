# 愛されポンコツ診断（ポンコツ図鑑）設計メモ v4

レポート『SNSでバズる診断コンテンツ調査』の第1位案「自虐ミームラベル診断」を、成功例を参考に作り込んだもの。v3では、診断を**かんたん診断（12問）**と**くわしい診断（＋24問）**の2段階に分けた。くわしい診断の結果は、ふんわりした部分だけを無料で見せる。くわしい部分にはモザイクをかけ、完全版を買うと読めるようにした。

- 名前はすべて仮。`site/assets/config.js` を変えれば全ページに反映される。
- 調査メモ・レビュー
  - v2: `research_notes/v2_benchmarks/`（結果ページの作り・マネタイズ）
  - v3.1 のレビュー: `research_notes/v3/review_code.md`（コード・決済・セキュリティ）、`research_notes/v3/review_copy.md`（文言・法令・10代の安全）。指摘はすべて反映した
  - v4: `research_notes/v4/uncovered_patterns.md`（まだ取り入れていなかった成功例の調査）、`research_notes/v3/review_paid_text.md`（有料の文章のレビュー）
  - v3: `research_notes/v3/paywall_patterns.md`（チラ見せ・ペイウォール・法規制）、`research_notes/v3/two_tier_and_viral.md`（2段階診断・二つ名・友達クイズ・2026年の10代トレンド）
- お金まわり: `docs/monetization.md`

## 位置づけと競合

- 中国のSBTI（2026年4月）にあたる、「MBTIの代わりに、笑える自虐ラベルを返す診断」の日本版。
- 日本の直接の競合は**悪口診断**（waruguchi16.jp）。詳しくは [競合チェック](competitor_check.md)。
  - 月1,945万PVの実績がある。
  - ラッコM&Aで売りに出ている案件とみられる。
- 悪口診断は、他人をディスる毒で売れた。こちらはその逆で、「自分を笑って、最後は愛される」自虐で差別化する。

## v3の全体像

```
ホーム ─┬─ かんたん診断（12問・約1分）─→ かんたん結果（無料・全部読める）
        │                                   └─ 「くわしい診断の続き（あと24問）」
        └─ くわしい診断（36問・約4分）──→ レポート全8章
                                            第1章 ステータス ……………… 無料（二つ名の解説の前半を見本に）
                                            第2〜3章 パラメータ・恋愛タイプ … 見出し・段階・冒頭の一言は無料、くわしい部分はモザイク
                                            第4〜8章 本当のあなた ほか ……… 見出しと予告は無料、本文はモザイク
                                            → 完全版（390円・買い切り）でモザイクが外れる
```

- 12問の結果（タイプ）は、24問を足しても**変わらない**。くわしい診断は「別の診断」ではなく「同じタイプの続きの章」。
  - 成功例が、詳細版でタイプを出し直していないことに合わせた。
  - 例: LoveType16の64通り、16PersonalitiesのA/T、ビッグファイブのファセット。
- かんたん診断を終えた人には、「続きから24問」で入れる入口を出す。進捗は「13/36問」から始まる。
- くわしい診断は8問ずつの3パートに分けた（レポートの「章」と区別するため「パート」と呼ぶ）。
  - パートの終わりごとに、そのパートで測った2つのパラメータのランクをシールのように貼って見せる。
  - パート2のあとは恋愛タイプを、パート3のあとは「？？？の〇〇」（二つ名の予告）を先に見せる。

## 判定の仕組み

### 4つの軸（かんたん診断）

| 軸 | 片側 | もう片側 |
|---|---|---|
| E | 省エネ | 全力 |
| S | ひとり好き | 人たらし |
| P | 計画派 | ノリ派 |
| M | 考えすぎ | 秒で忘れる |

- 1軸あたり3問、計12問（約1分）。
- 選択肢は −3／−1／+1／+3 の4択。1軸3問の合計は必ず奇数になるので、**引き分けが起きない**（−9〜+9）。
- 改行は文節の切れ目だけ（`site/assets/jptext.js`。画面では <wbr> と `word-break: keep-all`、画像では折り返しの単位）。「連絡／先」「インス／タ」のような単語の途中では切らない。
- 選択肢は、どの質問でも上から「控えめ → 全開」の順に並べ、左に絵文字を付ける（v4.3。以前は強弱の順に見えないようシャッフルしていたが、「選びにくい」という声があった。並びがばらばらだと、4つ全部を読んで頭の中で並べかえないと選べない）。1つの選択肢は1つの行動だけ・16字まで。好きな人や推しがいない人向けに「いなければ『もしいたら』で」の案内を出す。

### 6つのパラメータ（くわしい診断）

| パラメータ | 高いときの形容 | 低いときの形容 | 章 |
|---|---|---|---|
| 恋愛積極度 | 恋に全力な | 恋はのんびり派の | パート1 恋とヤキモチ |
| ヤキモチ度 | ヤキモチ焼きの | 心が広すぎる | パート1 |
| さみしがり度 | さみしがりの | ひとりでも平気な | パート2 さみしさと妄想 |
| 妄想力 | 妄想がとまらない | 地に足がついた | パート2 |
| 推し活熱量 | 推しが燃料の | 自分推しの | パート3 推しと笑い |
| ツッコミ力 | ツッコミが鋭い | 天然ボケの | パート3 |

- 1パラメータあたり4問。選択肢は 0〜3 点で、合計 0〜12 点を 0〜100% にのせる。
- 段階: 33%以下が「低め」、66%以下が「ふつう」、それより上が「高め」。
- ランク: 85%以上が S、67%以上が A、42%以上が B、25%以上が C、それ未満が D。
- **二つ名**: 50%からいちばん離れたパラメータの「高い／低い」の形容をタイプ名の前につける。
  - 例:「ヤキモチ焼きの」＋「既読スルー職人」
  - 同点のときに同じパラメータばかり選ばれないよう、比べ始める位置をタイプごとにずらす。
  - 形容12種 × 20タイプ ＝ 240通り。
- **恋愛タイプ**（8種）: 恋愛積極度・ヤキモチ度・さみしがり度の3つが58%以上かどうかの組み合わせ。

| 積極 | ヤキモチ | さみしがり | 恋愛タイプ | 相性のいい恋愛タイプ |
|---|---|---|---|---|
| − | − | − | マイペース恋愛型 | 一途なハンター型 |
| − | − | ＋ | かまって待ち型 | 全力ハグ型 |
| − | ＋ | − | 静かに燃える型 | さっぱり告白型 |
| − | ＋ | ＋ | こっそりヤキモチ型 | ひっつき虫型 |
| ＋ | − | − | さっぱり告白型 | 静かに燃える型 |
| ＋ | − | ＋ | ひっつき虫型 | こっそりヤキモチ型 |
| ＋ | ＋ | − | 一途なハンター型 | マイペース恋愛型 |
| ＋ | ＋ | ＋ | 全力ハグ型 | かまって待ち型 |

- **ステータス**（10項目のレーダー）
  - 4軸: その人が寄っている側の名前（省エネ／全力 など）と、その側への寄り具合（50〜100%）。かんたん診断と同じ値。省エネの人に「全力 D」と出さないため。
  - 6パラメータ: 恋愛積極・ヤキモチ・さみしがり・妄想・推し活・ツッコミ。
  - 無料では、ランクと4軸の％を見せる。6パラメータの％はモザイク。「S〜Dは高さの目安で、よい・わるいではありません」と添える。
- **必殺技と弱点**（無料）: いちばん高いパラメータの「必殺技」（例：「好きな人の変化に一瞬で気づく」）と、いちばん低いパラメータの「弱点」（例：「誘いを3日放置」）。シェア文にも入る。

### 隠しタイプ（4種類）

判定はこの順に見て、先に当たったものを採用する。くわしい診断でも、タイプはかんたん診断の12問だけで決まる。

1. **幻のしっかり者（S4）**: 4軸すべての合計が ±1 で、しかも ±3 の答えが4つ以下。理論出現率0.74%で、いちばんレア。
2. **スマホと融合した人（S1）**: スマホ系の選択肢（Q1・Q4・Q5）を3つとも選ぶ。
3. **金欠の妖精（S2）**: お金系の選択肢（Q7・Q11・Q12）を3つとも選ぶ。

### 結果コード

### 相性

- 軸ごとの組み合わせで点を足す。

  - 「考えすぎ/秒で忘れる」は、そろうと少し有利。
- 点を52〜99%にのせる。

  |---|---|
  | 90%以上 | 最強の相方 |
  | 80%以上 | 名コンビ |
  | 68%以上 | いい感じ |
  | それ未満 | 刺激しあう仲 |
  | 同じタイプ同士 | 分身 |

  v2の「運命の相方」は、占いに見えないように「最強の相方」に変えた。
- いちばん点が高い相手は、必ずデータ上の相性◎（上2つの軸を反転したタイプ）と一致する（テストで確認）。

### 記録するもの

Cloudflare D1 の `counters` に、回数だけを記録する。個人を識別する情報は受け取らない。

|---|---|
