# 愛されポンコツ診断 マネタイズ計画

調査の詳細と出典は `research_notes/v2_benchmarks/monetization.md`（v2）と `research_notes/v3/paywall_patterns.md`（v3のチラ見せ・決済・法規制）にある。このメモはその結論と、実装した内容、次にやることをまとめたもの。数字のうち実測でないものには「推定」と書いている。

## 前提

- 利用者の中心は10代後半〜20代前半の女性で、スマホから使う。流入元はTikTok・Instagram・X。
- 10代のお小遣いは、中学生で月約3,300円、高校生で月5,400〜6,400円。推し活への支出は月約6,000円（調査メモ1-5）。
- 10代はクレジットカードを持っていないことが多い。使える決済は、PayPay・キャリア決済・プリペイドが中心になる（調査メモ2章）。
- 診断サイトのPVは、バズで一気に増えて、その後急に落ちる。ラッコ案件（悪口診断とみられる）は、自社SNSを止めてから3か月でPVが約95%減った。月平均ではなく、**バズ1回でいくら残せるか**で設計する。

## 収益の柱（導入する順）

| 順 | 施策 | 価格・条件 | 状態 |
|---|---|---|---|
| ① | **AdSense＋オファーウォール**（リワード広告でおまけを解放） | 無料 | 未実装。AdSenseの審査を通ってから管理画面で設定する |
| ② | **LINEスタンプ・絵文字**（タイプ別キャラ） | 1セット120〜250円。作者への分配は約35% | 未申請。人の手で描いたイラストが完成したら、いちばん出ているタイプから申請する |
| ③ | **企業タイアップ診断**（B2B） | 1件30〜100万円（推定。制作＋プレイ数保証＋SNS投稿） | 営業資料が必要。月の診断完了が10万を超えたら始める |
| ④ | **完全版**（有料・買い切り。くわしい診断のモザイクを外す） | **390円**（ふたり用590円）。継続課金なし | **実装済み**（下に詳細） |
| ⑤ | **受注生産グッズ**（SUZURI・BOOTH） | アクスタ1,500〜2,000円、ステッカー400〜600円 | 未着手。在庫を持たずに、どのキャラが人気か確かめる |

①〜③は決済や未成年対応をこちらで抱えずに済む。④は単価が読みやすく、自分たちで価格を決められる。

## 実装した「完全版」（v3）

### 無料と有料の分け方

v3では、診断を**かんたん診断（12問・全部無料）**と**くわしい診断（＋24問）**に分けた。くわしい診断のレポート（全8章）は、ふんわりした部分を無料で見せて、くわしい部分にモザイクをかけている。

| 無料 | 完全版（モザイクが外れる） |
|---|---|
| かんたん診断の結果とタイプ解説（全部） | — |
| 二つ名・恋愛タイプ名・10項目のランク（S〜D）・4軸の％ | 6パラメータの％ |
| 6パラメータの段階（高め・ふつう・低め）と冒頭の一言 | 5パラメータのくわしい解説 |
| **二つ名のもとになったパラメータの解説（全文の見本）** | — |
| 恋愛タイプのキャッチと冒頭の一言・相性のいい恋愛タイプの名前 | 恋愛タイプの深掘り・恋のアドバイス3つ・相性の理由 |
| 第4〜8章の見出しと予告 | 本当のあなた／ポンコツを武器にする3つの方法／恋愛の落とし穴と攻略法／2027年の過ごし方ヒント／お守りメッセージ |
| 二つ名カード・プロフ帳カード | ステータスカード・ゴールドカード |

- この分け方は、調査（`research_notes/v3/paywall_patterns.md`）の「チラ見せ」の型に合わせた。
  - 自分についての何かが「ある」ことを確かに示す（章タイトル・段階・ぼかした実体）。
  - 量を示す（「のこり7章・約1,500字」「約180字」）。
  - 価格と買い切りであることを先に出す（「390円・1回だけ・自動更新なし」）。
  - 見本で質を確かめてもらう（第1章の見本は全文）。
- モザイクの下には本物の文章を置かない。同じ文字数のダミー文字をぼかして、購入後に出る量と一致させている。
- 購入率を見ながら、無料の量を15%・30%・45%で試すのが次の一手（調査メモ6-9）。

### 価格とプラン

| プラン | 価格 | 中身 | 設定 |
|---|---|---|---|
| じぶん用 | **390円**（税込・買い切り） | 全20タイプ分の完全版 | `STRIPE_PRICE_ID`（必須）・`PREMIUM_PRICE` |
| ふたり用 | 590円（税込・買い切り） | じぶん用＋友達1人に贈れるプレゼント用リンク | `STRIPE_PRICE_ID_DUO`・`PREMIUM_PRICE_DUO`（設定したときだけ出る） |

- 390円は、10代が推し活のついでに払える額にそろえた。
  - 有料の相場は、ラブタイプ診断の個人鑑定980円、16TEST+の1,100円、16Personalitiesの29ドル。
- 「通常価格〇〇円→390円」のような二重価格は使わない（景品表示法）。
- ふたり用は「友達と相性をくらべる」遊び方とつながる。贈られた友達の端末でも完全版が開くので、拡散にもつながる。

### 購入の流れ

1. **購入案内**
   - 入口: 画面下の固定バー、第1章の直後のボタン、モザイクのタップ。
   - 第2章が見えたところで、**1回だけ**自動で出す。2回目からは、ボタンを押したときだけ。
2. **自社の最終確認画面**（特定商取引法12条の6）
   - 商品と分量・価格・支払時期と方法・提供時期・申込期間・キャンセルの6項目を表示する。
   - 確認のチェックボックスと、「18歳未満は保護者の同意を」の表示がある。
   - ボタンは「390円を支払って購入する」。
3. **Stripe Checkout**: カード・Apple Pay・Google Pay。PayPayは、Stripeの審査に通ればダッシュボードで有効にできる。
4. **`/thanks/` に戻る**
   - `/api/unlock` が支払いを確かめて、購入トークン（`v1.<購入ID>.<署名>`）を発行する。
   - 引き継ぎリンクと、ふたり用ならプレゼント用リンクを表示する。

### おうちの人に払ってもらう

10代はクレジットカードを持っていないことが多い（高校生のQR決済の利用は50.8%で、残高は親からの送金が多い）。そこで、親のスマホで払ってもらう流れを用意した。

1. 子どもが「おうちの人に払ってもらう」を押すと、受け取りID（16文字）入りのリンク `#/buy/<受け取りID>` ができる。LINEなどで親に送る。
2. 親が開くページには、商品の中身・価格・「占いではありません」の説明だけを出す。子どもの診断結果や回答は見せない。
3. 親が払うと、Stripeの `client_reference_id` に入れた受け取りIDで、サーバー（D1の `claims`）に購入トークンを置く。
4. 子どもの端末は、開いている間だけ `/api/claim` を5秒ごとに確かめる。トークンが届いたら、自動で完全版が開く。
   - 受け取りIDは7日で使えなくなる（子どもの端末でも、サーバーでも）。
5. 親の画面にも、引き継ぎリンクを出す（子どもの端末が自動で開かなかったときのため）。

### 端末の引き継ぎ・コード

- アカウント登録はなし。購入トークンは端末のブラウザに保存する。
- 別の端末で読むとき
  - 購入後に出る**引き継ぎリンク**（`#/unlock/<トークン>`）を開く。
  - または、「コード・引き継ぎリンクで開く」にリンクを貼る。
- キャンペーンやタイアップ用のコード（`PROMO_CODES`）でも開けられる。B2Bの「参加者全員に完全版をプレゼント」にそのまま使える。

### 仕組み

| 項目 | 実装 |
|---|---|
| 有料の文章の置き場所 | サーバー（`functions/_lib/premium.js`）だけ。ブラウザに配るファイルには、文字数しか入れない |
| 本文の返し方 | 購入トークンを持つ人にだけ、`/api/premium?i=タイプ&p=パラメータ` で返す。その人のパラメータの段階に合った解説を選んで返す |
| 第1章の見本 | `/api/sample` が、二つ名のもとになった1項目の解説だけを無料で返す。決め方はブラウザ側と同じ（テストで一致を確認） |
| トークン | HMACで署名する。データベースに購入記録はいらず、偽造したトークンは弾く |
| 特定商取引法に基づく表記 | `#/legal`。販売事業者名などは `site/assets/config.js` の `seller` を埋める。価格はサーバーの設定値を表示する |

### 決済まわりの注意

- **Stripe Japanは「占い」が禁止業種**（Psychic services and fortune tellers）。コンビニ決済はさらに、「非科学的・迷信に基づくコンテンツ」も対象になる。
  - そのため、完全版は「エンタメの心理テスト・自己分析」として作った。星座・運勢・「相性占い」の言葉は使っていない。
  - 「2027年のあなた」は「2027年の過ごし方ヒント」に変えた。中身も予言ではなく、行動の提案として書いている。
  - 相性のランク名も「運命の相方」から「最強の相方」に変えた。
  - `scripts/validate-content.mjs` で、占いの語（占い・鑑定・運勢・守護霊など）と予言の語（「〜するでしょう」など）を検査している。
  - 販売の前に、**Stripe（またはKOMOJU）に業種審査が通るかを問い合わせる**。
- **やらないこと**（消費者庁のダークパターン類型）
  - 偽のカウントダウン
  - 「残りわずか」
  - 自動生成の購入者数
  - 購入案内を何度も自動で出すこと
  - 罪悪感をあおる文言
- **手数料**: Stripeのカードは3.6%。PayPayは、デジタルコンテンツ事業者だと9.48%。
- **キャリア決済**: Stripeでは使えない。10代に一番届くのはKOMOJU経由のキャリア決済（6.6%〜）なので、販売が伸びたら第2の決済手段として検討する。
- **未成年の購入**
  - 民法では、お小遣いの範囲の少額なら取り消しにくい。ただし、「成年ですか？」に「はい」を押させるだけでは守られない。
  - 保護者から申し出があれば全額返金する運用にして、特定商取引法の表記にも書いた。
  - 「おうちの人に払ってもらう」流れは、同意を得たことを明確にする役目もある。

## 広告の置き方

- 結果の前の全画面広告は入れない（悪口診断がやっているが、シェアの直前に体験を壊す）。
- 結果ボタン・シェアボタン・選択肢の近くには置かない（誤クリックを誘う配置はAdSenseのポリシー違反）。
- 置く場所は、結果ページの「学校・バイト」と「トリセツ」の間、図鑑の下、タイプページの末尾。
- オファーウォールは、おまけ（例：「推しを当てはめるなら」診断、壁紙）の解放だけに使う。完全版と同じものを広告で開けられるようにはしない。

## 収益の試算（すべて推定）

| 月の診断完了数 | ディスプレイ広告 | オファーウォール | 完全版（診断完了の0.3%） | LINEスタンプ | B2B | 合計 |
|---|---|---|---|---|---|---|
| 10万 | 約4.5万円 | 約0.8万円 | 約10.5万円 | 約1.8万円 | 0 | 約18万円 |
| 30万 | 約13.5万円 | 約2.3万円 | 約31.6万円 | 約5.3万円 | 約30万円（1件） | 約83万円 |
| 100万 | 約45万円 | 約7.5万円 | 約105万円 | 約17.5万円 | 約120万円（2件） | 約295万円 |

- いちばん不確かなのは**完全版の購入率**。0.1%なら上の3分の1、1%なら3倍強になる。
  - v3では、くわしい診断に進んだ人（目標25%）のうち1.5%が買うと、診断完了全体の約0.4%になる。
  - 上の表の0.3%は、それより控えめに置いた値。
- ラッコ案件の広告収入は、ピーク月（1,945万PV）で約199万円だった。完全版とB2Bを足すことで、同じバズから2倍前後を残すのが目標。

## 次にやること

1. **業種審査の確認**: Stripe（とKOMOJU）に、性格診断の有料レポートが審査に通るか問い合わせる。
2. **環境変数を設定して公開する**
   - `STRIPE_SECRET_KEY`、`STRIPE_PRICE_ID`（390円の価格ID）、`PREMIUM_SECRET`（長いランダム文字列）を設定すると、販売が始まる。
   - ふたり用も売るなら `STRIPE_PRICE_ID_DUO`（590円の価格ID）を足す。
3. **購入率を測る**: 公開から2週間、`/api/stats?all=1` で次の数を比べる。

   | 段階 | キー |
   |---|---|
   | くわしい診断の完了 | `detail:done` |
   | 購入案内の表示 | `paywall:view`・`paywall:cta` |
   | おうちの人へのお願い | `paywall:ask` |
   | 決済画面へ進んだ数 | `premium:checkout` |
   | 支払い完了 | `premium:paid:solo`・`premium:paid:duo` |

   どこで落ちているかを見て、無料の量・コピー・プランの数を1つずつ試す。
4. **LINEスタンプを申請する**: 人の手で描いたキャラが完成したら、いちばん出ているタイプから申請する。
5. **B2Bの営業資料を作る**: 診断完了が10万を超えたら、実績の数字を入れて作る。悪口診断のように、配信・動画での利用を自由にするプレスキットも用意する。
