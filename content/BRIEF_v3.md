# くわしい診断の文言 執筆ガイド（v3）

前提とトーン・表記・NGルールは `content/BRIEF.md` と同じ。ここでは、くわしい診断で増える文言だけを説明する。

## しくみ

- **くわしい診断で測るもの**: 4つの軸に加えて、6つのパラメータを測る（各3問、0〜100%）。
- **パラメータの3段階**: 低め（0〜33%）・ふつう（34〜66%）・高め（67%以上）に分け、段階ごとに文言を出す。
- **恋愛タイプ**: 恋愛積極度・ヤキモチ度・さみしがり度の高低（50%以上を「高」）で、8種類に分ける。
- **無料と有料の分け方**:

  | | 中身 | 見せ方 |
  |---|---|---|
  | 無料（ふんわり） | `lead` と恋愛タイプの `name`・`catch` | そのまま見せる |
  | 有料（くわしく・具体的） | `detail`・`tips`・`bestWhy` | 課金するまでモザイク |

  `lead` を読むと「当たってる、続きが読みたい」と思い、`detail` を読むと「ここまで自分のことだ」と感じる、という差をつける。

## パラメータ（content/params.json）

| キー | 名前 | 高いと | 低いと |
|---|---|---|---|
| koi | 恋愛積極度 | 自分から追いかける | 待つ・様子を見る |
| yaki | ヤキモチ度 | 好きな人・友達・推しのことで心がざわつく | おおらか |
| samishi | さみしがり度 | 人とつながっていたい | ひとりでも平気 |
| mousou | 妄想力 | 「もしも」や未来を想像しがち | 現実的 |
| oshi | 推し活熱量 | 推しが生活の中心 | 推しより自分 |
| tsukkomi | ツッコミ力 | ツッコむ・笑いに変える | 天然・素直に受け取る |

`params.json` は `{ "koi": [低め, ふつう, 高め], ... }` の形。各段階は次の2つを持つ。

- `lead`（無料・25〜60字）: その段階の人の、ふんわりした特徴。
- `detail`（有料・140〜230字）: 具体的な場面を入れた深掘り。最後に、明日からできる一言アドバイスを入れる。

見本は `yaki` の「高め」。低め・ふつうも同じ質で書く。低めの段階も、欠点ではなく魅力として書く。

## 恋愛タイプ（content/love.json）

番号 = 恋愛積極度が高い(4) ＋ ヤキモチ度が高い(2) ＋ さみしがり度が高い(1)。

| 番号 | 名前 | 積極 | ヤキモチ | さみしがり |
|---|---|---|---|---|
| 0 | マイペース恋愛型 | 低 | 低 | 低 |
| 1 | かまって待ち型（見本） | 低 | 低 | 高 |
| 2 | 静かに燃える型 | 低 | 高 | 低 |
| 3 | こっそりヤキモチ型 | 低 | 高 | 高 |
| 4 | さっぱり告白型 | 高 | 低 | 低 |
| 5 | ひっつき虫型 | 高 | 低 | 高 |
| 6 | 一途なハンター型 | 高 | 高 | 低 |
| 7 | 全力ハグ型 | 高 | 高 | 高 |

各タイプのキーと文字数:

| キー | 中身 | 文字数 |
|---|---|---|
| index | 番号 | — |
| name | 名前（表の名前を使う） | 4〜12 |
| catch | 一言キャッチ | 6〜18 |
| lead | 無料の説明 | 40〜80 |
| detail | 有料の深掘り（恋のはじまり方・落とし穴・攻略） | 160〜240 |
| tips | 有料のアドバイス3つ | 各8〜30 |
| best | 相性のいい恋愛タイプの番号 = `index ^ 6`（積極度とヤキモチ度が逆で、さみしがり度が同じ相手） | — |
| bestWhy | 有料。その相手と合う理由 | 15〜45 |

## 書き方の注意

- 10代が多い。恋愛の場面は、学校・バイト・推し・メッセージのやりとり・デート（ごはん・映画・遊園地など）にとどめる。性的な話題、同棲、結婚生活は書かない。
- 性別を決めつけない（「好きな人」「相手」）。
- 「占い」に見える言葉（運勢・運命・星座・前世など）を使わない。予言の言い回し（〜がありそう、〜が訪れる）も使わない。未来のことは、行動の提案として書く。
- 執着や束縛を肯定しない。ヤキモチ度が高いタイプは、「素直に伝える」「相手を信じる」方向で着地させる。
